## Adding more music

1. Use tracks you have the **legal right** to host (royalty-free license, CC0, purchased license, or your own composition).
2. Drop the `.mp3` (or `.ogg`) into this `audio/` folder.
3. Add the path to the `TRACKS` array in `JS/music.js`.
4. Note the license/source in this file.

Do **not** embed YouTube, Spotify, or other iframe players for BGM — school networks and GitHub Pages constraints make that unreliable, and many services disallow embedding that way.
